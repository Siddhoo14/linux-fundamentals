## What is Linux?

Linux is an open-source operating system kernel created by Linus Torvalds in 1991.  
It is widely used in servers, cloud computing, DevOps, cybersecurity, and enterprise environments.

Linux is known for:
- Stability
- Security
- Performance
- Flexibility
- Multi-user support

Today, most cloud platforms and servers run on Linux.

---

# Why Learn Linux for DevOps?

Linux is one of the most important skills for a DevOps Engineer because:

- Most servers run on Linux
- Docker containers use Linux
- Kubernetes works heavily with Linux
- Cloud VMs are mostly Linux-based
- Automation and scripting are easier in Linux

# Features of Linux

## 1. Open Source
Linux source code is publicly available and can be modified by anyone.

---

## 2. Multi-User
Multiple users can work on the same system simultaneously.

---

## 3. Secure
Linux has strong permission and security mechanisms.

---

## 4. Stable
Linux servers can run continuously for months or years without rebooting.

---

## 5. Portable
Linux can run on:
- Laptops
- Servers
- Cloud VMs
- Mobile devices
- Supercomputers

---

## 6. Command Line Interface (CLI)
Linux provides powerful command-line tools for automation and administration.

Example:

```bash
pwd
ls
mkdir
```

## 1. Kernel
The core part of Linux.

Responsibilities:
- Memory management
- Process management
- Device management
- File system handling

---

## 2. Shell
Shell acts as an interface between the user and the kernel.

Popular shells:
- Bash
- Zsh
- Sh

Example command:

```bash
echo "Hello Linux"
```

---

## 3. File System
Linux organizes everything as files and directories.

Example:

```bash
/home
/etc
/var
```
